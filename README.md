# Лабораторная работа №1: Первичное исследование и оценка качества данных

## Описание проекта
В рамках данной лабораторной работы проводится разведочный анализ данных (EDA), аудит качества и выявление аномалий для датасета `Attribute_DataSet.csv`, содержащего характеристики женской одежды (платьев).

## Структура проекта
- `notebooks/` — Jupyter Notebook с этапами выполнения лабораторной работы (`01_data_understanding.ipynb`).
- `data/` — исходный набор данных (`Attribute_DataSet.csv`).
- `report/` — текстовый отчёт с результатами аудита качества и планом улучшений (`quality_report.md`).
